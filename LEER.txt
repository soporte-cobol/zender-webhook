¡Hola! Bienvenido al Bot Inteligente para Zender + WooCommerce 🤖✨

Este proyecto ha evolucionado para ser una solución de ventas "Plug & Play". 
Ahora cuenta con un motor de Inteligencia Artificial (Gemini) que genera respuestas naturales y persuasivas, y un carrito de compras avanzado que permite al usuario agregar, quitar, cambiar cantidades o vaciar el pedido con lenguaje natural (ej: "quiero 3 unidades", "quita la máquina", "vaciar carrito").

Para comenzar, por favor dirígete al archivo principal de documentación:
👉 README.md

En el README encontrarás instrucciones paso a paso, redactadas de manera sencilla (incluso si no tienes experiencia previa), sobre:

- 📦 Instalación y dependencias.
- ⚙️ Configuración de variables de entorno (incluyendo tu API Key de IA).
- 🔌 Cómo conectar los Webhooks de Zender y WooCommerce.
- 💰 Configuración dinámica de descuentos, categorías y envíos.
- 🚀 Cómo desplegar en tu hosting (cPanel).

¡Mucho éxito con tus ventas en piloto automático!
